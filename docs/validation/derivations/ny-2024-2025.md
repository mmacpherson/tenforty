## Eligibility, income and household count

The NYS household credit is IT-201 line40, distinct from NYC line48.
A taxpayer claimable as another taxpayer's dependent (itemC Yes) receives0.
For itemC No, choose the table by filing status. All three tables and their
thresholds are identical in 2024 and2025.

The income variable is federal AGI (line19), not NY AGI or NY taxable income.
Special-condition A6 Build America Bond interest included in line19 is
subtracted for this test (notes1/4). Zero and negative income use the first row.
Each upper endpoint is inclusive: 'over lower, but not over upper'. Above the
last upper endpoint no credit is allowed.

Single uses table1 regardless of dependent count. MFJ, HOH and qualifying
surviving spouse use table2. The table2 count is itemH dependents plus1 for the
filer, plus1 for a spouse ONLY for MFJ. Thus count=dependents+2 for MFJ,
count=dependents+1 for HOH/QSS. QSS has no surviving-spouse baseline exemption.

MFS uses table3: income is BOTH spouses' federal AGIs after note4 A6
adjustments, even if the spouse did not file an NY return. The count is
both returns' itemH/itemI dependents plus2 (filer and spouse). Do not infer
spouse AGI=0 or spouse dependent count=0 from MFS status. Separate-return
cross-spouse inputs and claimability need an explicit supported-surface
decision; that decision does not change the source derivation.

For count>7, add the printed last-column increment for EACH individual above7
to the printed column7 value (note3). Table3 is already dollar-rounded (note5):
do not compute it by halving table2, especially in the over7 extension.

## Boundary test plan fixed before implementation inspection

For every table row, evaluate upper−1, upper, upper+1, each printed household
column1–7 and counts8/9/12. The next row applies only at upper+1. Include
negative/zero AGI and the final cutoff. For Table2, reachable status bases

spouse-income/dependent interactions, nonrefundability and natural scalar/batch
mapping wherever the approved public input surface can express the case.
