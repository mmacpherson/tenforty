## Child deduction and rounding repair (2026-11-04, b72.52)

The original derivation and all 46 source return outcomes above are unchanged.
All 42 NC graph defect signatures reported exact matches before retirement.
The graph now computes the published child-deduction table and rounds the
required entries/tax to whole dollars. These corrections retire both the child
and NC-specific rounding departures; the global b72.42 rounding work remains
open for other states. NC2024/2025 enter graph scope with the original official
fixture evidence.

D-400 line10a consumes the existing `schedule_8812_qualifying_children` count:
`num_ctc_dependents` when supplied, otherwise `num_dependents`. This respects
the archive's case8/A6 premise (IRC24 qualifying children) and does not give the
child deduction to qualifying relatives receiving only the federal credit for
other dependents. This choice was approved in SOL-20; no new natural field is
added. Raw graphs use `nc_d400_QualifyingChildren`. The deduction uses rounded
federal AGI, not state AGI after additions/subtractions, and its upper limits
are inclusive.

`tests/nc_child_deduction_test.py` checks the original 46 whole-return outcomes,
all statuses/years at every table edge, zero/one/two qualifying children, CTC
subsets independent of total dependents, zip lowering, and the p.4 positive
half-dollar entry rule. The component/entry controls apply archived source
rules; they are not a new blind whole-return derivation. No source expected
value was generated or adjusted from backend output. Existing negative-taxable
income representation (r91.7) remains unchanged: case22 pins only its zero tax.
