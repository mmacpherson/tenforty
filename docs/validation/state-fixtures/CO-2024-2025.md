Each alternative is a whole outcome; the test never pairs taxable income from one reading with tax from another.

  applied only where the table row and rate × income differ.

  bound ± $0.50, applied only where rate × taxable income has cents.

- At exactly $300,000 the graph follows the booklet reading.

Every departure is a strict, bounded signature in `GRAPH_DEFECTS`: the test
fails if the graph leaves the bound, and also if it starts matching. Bounds
come from each defect's mechanism and the record's own figures, never from the
observed residual. CO stays out of graph scope (`tenforty.graph_scope`) while
any of these beads is open.
