# Louisiana IT-540 fixtures, tax year 2024

Deriver: author agent for tenforty-x08, 2026-10-02. **Not blind.** The deriver had
read the repo's LA spec and had run the graph before the values below were fixed.
Every expected value is read off, or carried forward from, an LDR publication.
None of them is taken from graph output or from a repo table.

Labels differ by case:

- **`published-table-row`**: the W-2-only cases inside the table, where line 10 is
  read straight from a printed row and exemption column.
- **`unverified-legacy`**: the three cases above the table (Single $60,000, MFJ
  $150,000, Single $80,000). Their value is a small derivation: the last printed
  row, plus the table's continuation rule, plus nearest-dollar rounding. They were
  derived non-blind, so they are neither printed rows nor independent. They carry
  the deriver identity but, by the provenance policy, no record path; this file
  holds their arithmetic.

## Rules used

- I24 p.3: line 9 is federal AGI less line 8D (excess medical; zero here). Line 10 is
  read from the tax table for the line 9 amount and the exemption count on line 6F.
  "About This Form", item 4: round all entries to the nearest dollar.
- T24 headers: the combined personal exemption-standard deduction is $4,500
  (Single/MFS, pp.1-2) or $9,000 (MFJ/QSS, pp.3-6, where the first column is 2
  exemptions; HoH, pp.7-8). Each exemption after the first adds $1,000.
- T24, last row of each status: "Plus 4.25% of Tax Table Income in Excess of
  $51,000" ($101,000 for MFJ/QSS). Read here as the last row's value plus 4.25% of
  the excess, then rounded to the nearest dollar, half up, per I24 item 4.
- RIB p.1, note 1: the exemptions come off the lowest bracket first. This is used
  only to explain the graph's formula and its gap from the table, never to set an
  expected value.
- Out of scope: more than eight exemptions (T24 header: reduce table income by
  $1,000 for each exemption over eight, then read column eight).
