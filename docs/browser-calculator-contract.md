# Browser calculator contract

The browser calculator consumes a versioned contract rather than naming tax-form
graph nodes in UI code. The machine-readable source is
[`browser_contract.json`](../crates/tenforty-graph/demo/browser_contract.json).
It is generated from the same Python graph mappings used by `GraphBackend`, then
checked against the resolved graphs and independent pinned scenarios.

## Supported surface

Contract version 1 supports tax years 2024 and 2025, federal-only calculations,
all 50 states, and the District of Columbia. “Supported” means the resolved graph
contains the declared nodes and can calculate the listed public concepts. It does
not imply that every line of every return is modeled.

The public inputs cover wages, interest, dividends, capital gains and losses,
self-employment income, rental income, other Schedule 1 income, aggregate
itemized deductions, ISO exercise spread, and the business fields needed for the
qualified-business-income limitation. Filing status and jurisdiction are explicit
dimensions. Missing inputs default to zero; qualified dividends are included in
ordinary dividends; and the Social Security wage-base interaction is derived for
non-joint self-employed filers exactly as it is in `TaxReturnInput`.

The direct outputs are federal AGI, taxable income, QBI deduction, AMT,
self-employment tax, NIIT, Additional Medicare Tax, federal total tax, and each
state graph's available AGI, taxable-income, and total-tax quantities. Derived
outputs have named formulas:

- federal income tax is federal total tax less self-employment tax, NIIT, and
  Additional Medicare Tax;
- combined total tax is federal total tax plus state total tax;
- federal, state, and combined effective rates divide their respective tax by
  federal AGI and return zero when AGI is non-positive.

A next-dollar rate means the composed right-hand derivative of a public output
with respect to every graph node written by one public input. That includes
federal fan-out, state-side nodes, and active derived inputs. A single accidental
node-to-node partial is not a public marginal rate. The WASM boundary returns a
grouped gradient vector: smooth public inputs share one reverse traversal per
output, while active thresholds retain the graph runtime's right-hand convention.
The calculator derives combined effects by adding the federal and selected-state
vectors entry by entry.

## Failure and accuracy contract

Unknown years, jurisdictions, filing statuses, public inputs, missing graph nodes,
non-finite values, and unsupported state/year input combinations are errors. They
must never be converted to a displayed zero. A state quantity that the state graph
does not define is `null`; a modeled no-income-tax result is numeric zero.

The executable contract has two halves:

1. Python tests regenerate the manifest and compare its pinned federal and state
   values and gradient regions with `GraphBackend`.
2. The Pages smoke test loads the same manifest through the public WASM API,
   validates every declared node for both years and every jurisdiction, and runs
   the same pinned values and gradient vectors. The gradient pins cover an
   ordinary bracket, capital-gain stacking, AMT, Additional Medicare Tax and
   NIIT, and a state-side income node. A deliberately stale node must raise.

This makes the checked-in scenario values a bridge between Python and the browser
rather than deriving either side's expected result from the other at test time.

## Provenance and limitations

The per-year metadata in the contract comes from the resolved graph generated by
the Haskell tax specification and includes the graph's SHA-256 fingerprint.
OpenTaxSolver and Tax-Calculator remain independent test references; neither is a
browser computation backend.

The contract records its user-visible limitations directly. The initial browser
surface excludes dependent-related federal credits and ambiguous aggregate state
adjustment/exemption inputs. The legacy deduction choice is explicit: `Standard`
means automatic best-of and `Itemized` forces the supplied amount even below the
standard deduction. Results estimate modeled income taxes before payments and
refundable credits and are not tax-return filing advice.

Regenerate and validate after changing a Python mapping or public concept:

```console
uv run python scripts/generate_browser_contract.py --write
uv run pytest tests/browser_contract_test.py
node scripts/smoke_wasm_demo.mjs target/pages
```

The calculator renders its supported fields and dimensions from this contract.
Its DOM layer passes a public scenario to the same calculation boundary exercised
by the Pages smoke test; that test also round-trips every pinned scenario through
the share-link encoding before comparing its WASM result with Python. Share links
put scenario data after the URL fragment marker so it remains client-side.
